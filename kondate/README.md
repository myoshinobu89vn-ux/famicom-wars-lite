# 家庭料理献立アプリ（仮）

保有食材・ジャンル・調理時間・履歴から、家庭料理の主菜を自動で提案するアプリです。材料の過不足チェックは裏側で自動判定され、ユーザーはチェックボックス操作だけで済みます。画面右上に現在のバージョンを表示している。

詳細な仕様（画面構成・データ構造・ロジック・バージョン履歴）は [SPEC.md](SPEC.md) を参照。

## 使い方

1. トップ画面でジャンル（和・洋・中・他／複数選択可）・調理時間（10/20/30/45分）・人数（1〜6人前）を選ぶ
   - 「キーワード検索」に料理名や食材名（例: 鶏、パスタ、ケバブ）を入力すると、料理名・特徴の説明文・主要食材にその文字列を含む料理だけに絞り込める。空欄にすればすぐに解除される
2. 「時間優先」をONにすると、選んだ時間ぴったりの料理だけに絞り込む（OFFなら選んだ時間以内の料理すべてが対象）
3. 「調達不要のみ表示」をONにすると、今ある食材だけで作れる（買い足し不要な）料理だけに絞り込む。OFFにするといつでも解除できる
4. 「保有食材」ページで、家にある食材・調味料にチェックを入れる（切り替えると即座に保存される）
5. トップ画面で「献立を決める」を押すと、条件に合う献立候補が「作れる」「調達必要」に自動判定されて一覧表示される。各候補には料理の特徴を一言で紹介する説明文もついている
6. 調達必要な料理には不足材料が表示される
7. 「簡易レシピを見る」を押すと、選んだ人数分に分量を換算した材料リスト・作り方の手順・💡プロのコツ・メモ欄が展開表示される（あくまで目安の簡易レシピ）。メモは自由記述で入力するとそのまま自動保存され、次にそのレシピを開いたときも残っている
   - パネル上部のプルダウンでレシピサイト（クックパッド／クラシル／DELISH KITCHEN／YouTube／Google／Bing）を1つ選び、「GO」を押すとそのサイトの検索結果を新しいタブで開く。選んだサイトは記憶され、次にレシピを開いたときも初期選択される。トップ画面の「レシピ検索サイト」で除外したサイトはプルダウンの候補に出てこない。検索語は「料理名＋主要食材（最大2つ）＋レシピ」をスペースで区切って組み立てており、造語っぽい料理名でも主要食材のキーワードでヒットしやすくしている
8. 「ランダムに並べ替え」を押すと、表示中の候補の順番だけをシャッフルできる（決め手がないときに便利）
9. 「条件を変える」（候補一覧の上部）または「トップへ戻る」（下部）でいつでも選択画面に戻れる
10. 作った料理は「作ったよ」を押すと履歴に記録され、ボタンの色が変わって作ったことが分かる。もう一度押すと記録を取り消して元に戻せる。作った料理でも候補からは除外されない

## データ構成

- `data.js`
  - `INGREDIENT_CATEGORIES` : 保有食材のカテゴリ定義（肉類・卵豆腐・魚介類・野菜・乾物缶詰・乳製品）
  - `SEASONING_TABS` : 調味料タブ定義（和・洋・中・その他）。その他タブにはコチュジャン・ナンプラー・カレー粉・クミン・パプリカパウダーなど世界各国の調味料も含む
  - `INGREDIENT_SERVING_INFO` : 食材ごとの1人前あたりの目安量（分量・単位）。人数調整時の分量換算に使う。塩・こしょうなど人数によらず一定の食材は `fixed`（「少々」など）で表現する
  - `DISHES` : 主菜200品（和食・洋食・中華・他の定番100品 ＋ 日本の郷土料理40品・海外の国民料理60品）のデータ。各料理は `name` / `genre` / `time` / `description`（料理の特徴を紹介する一言説明）/ `need`（必要食材キーの配列）/ `steps`（作り方の手順配列）/ `tips`（プロのコツの配列）を持つ
- `script.js`
  - `RECIPE_SITES` : レシピ検索先サイトの定義（サイト名・検索URLテンプレート）。クックパッド／クラシル／DELISH KITCHEN／YouTube／Google／Bingに対応
- 保有食材・履歴・レシピメモ・除外したレシピサイトは `localStorage` に保存される（`kondate_ingredients_v1` / `kondate_history_v1` / `kondate_memos_v1` / `kondate_excluded_sites_v1`）

## 判定ロジック

- **作れる**: `need` の食材がすべて保有食材でONになっている
- **調達必要**: `need` の中に保有食材がOFFのものが含まれる。不足分を抽出して表示する

## ローカルでの動作確認

このディレクトリの `index.html` をブラウザで直接開くだけで動作します。ビルドやサーバーは不要です。

## GitHub Pagesでの公開

このリポジトリを GitHub Pages で公開している場合、`https://<ユーザー名>.github.io/<リポジトリ名>/kondate/` でアクセスできます。

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・外部ライブラリ・CDN依存なし）
- データ保存はブラウザの `localStorage` のみ（サーバー・DB不要）
