# 家庭料理献立アプリ（仮）

保有食材・ジャンル・調理時間・履歴から、家庭料理の主菜を自動で提案するアプリです。材料の過不足チェックは裏側で自動判定され、ユーザーはチェックボックス操作だけで済みます。

## 使い方

1. トップ画面でジャンル（和・洋・中・他／複数選択可）と調理時間（10/20/30/45分）を選ぶ
2. 「時間優先」をONにすると、選んだ時間ぴったりの料理だけに絞り込む（OFFなら選んだ時間以内の料理すべてが対象）
3. 「保有食材」ページで、家にある食材・調味料にチェックを入れる（切り替えると即座に保存される）
4. トップ画面で「献立を決める」を押すと、条件に合う献立候補が「作れる」「調達必要」に自動判定されて一覧表示される
5. 調達必要な料理には不足材料が表示される
6. 作った料理は「作ったよ」を押すと履歴に記録され、直近に作った料理（最新5件）はしばらく候補から除外される（マンネリ防止）

## データ構成

- `data.js`
  - `INGREDIENT_CATEGORIES` : 保有食材のカテゴリ定義（肉類・卵豆腐・野菜・乾物缶詰・乳製品）
  - `SEASONING_TABS` : 調味料タブ定義（和・洋・中・その他）
  - `DISHES` : 主菜100品（和30／中30／洋30／他10）のデータ。各料理は `name` / `genre` / `time` / `need`（必要食材キーの配列）を持つ
- 保有食材の状態と履歴は `localStorage` に保存される（`kondate_ingredients_v1` / `kondate_history_v1`）

## 判定ロジック

- **作れる**: `need` の食材がすべて保有食材でONになっている
- **調達必要**: `need` の中に保有食材がOFFのものが含まれる。不足分を抽出して表示する

## ローカルでの動作確認

このディレクトリの `index.html` をブラウザで直接開くだけで動作します。ビルドやサーバーは不要です。

## GitHub Pagesでの公開

このリポジトリを GitHub Pages で公開している場合、`https://<ユーザー名>.github.io/<リポジトリ名>/kondate/` でアクセスできます。

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・外部ライブラリ・CDN依存なし）
- データ保存はブラウザの `localStorage` のみ（サーバー・DB不要）
