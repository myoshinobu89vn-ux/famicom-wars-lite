# タイプ相性クイズ

ポケモンGOにおける「あるタイプの相手に対して効果抜群な攻撃タイプ」を学習するための3択クイズアプリです。

## 遊び方

1. 表示された防御側タイプに対して効果抜群な攻撃タイプを、3つの選択肢から選ぶ
2. 回答すると正解・不正解が色分けで表示され、効果抜群な攻撃タイプの一覧と解説が表示される
3. 「次の問題へ」ボタンで次の問題に進む（無限にループ）

## ローカルでの動作確認

このディレクトリの `index.html` をブラウザで直接開くだけで動作します。ビルドやサーバーは不要です。

## GitHub Pagesでの公開

このリポジトリを GitHub Pages で公開している場合、`https://<ユーザー名>.github.io/<リポジトリ名>/pokemon-type-quiz/` でアクセスできます。

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・外部ライブラリ・CDN依存なし）
- オフラインでも動作する静的サイト構成
