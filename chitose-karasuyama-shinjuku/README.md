# 千歳烏山→新宿 次発電車比較

京王線 千歳烏山駅から新宿方面への移動時、現在時刻から15分以内に発車する電車を一覧表示し、
新宿(または新線新宿・都営新宿線方面)へ最も早く着く電車を強調表示するツールです。

## 使い方

このディレクトリの `index.html` をブラウザで開くだけで動作します。ビルドやサーバーは不要です。

- 上部に現在時刻を表示し、1秒ごとに一覧を更新します
- 各電車のカードには、発車時刻・種別・新宿(方面)到着予定時刻・残り時間を表示します
- 一覧中で新宿到着が最も早い電車には「最速」バッジを表示します
- 各カード下部の「見送ると…」の行で、その電車を見送って後続の電車に乗り換えた場合の
  到着時刻・差分を確認できます(後続の急行系が先に着く場合はプラス表示、遅くなる場合は
  マイナス表示になります)

## データについて・既知の制約

- 収録している時刻表は **平日ダイヤのみ** です。土休日ダイヤのデータは未取得のため、
  土休日にアクセスすると平日ダイヤを参考表示し、その旨を画面上部に注記します。
- 時刻表データ(`data.js`)は、京王電鉄「発車標準時刻表」(2026年8月17日改正・千歳烏山駅
  下り新宿方面)をユーザーが書き起こしたものをもとに作成しています。祝日ダイヤ(土休日扱い)
  は未対応で、`getDayType()` は曜日(土・日)のみで平日/土休日を判定しています。
- 種別ごとの千歳烏山→新宿所要時分は次の値を採用しています。特急(12分)・区間急行(14分)は
  複数の乗換案内サイトの表示から確認済みです。快速・各停(20分)は同様の情報源からの概算値です。
  **急行(14分)は、千歳烏山→新宿間で区間急行と同じ停車駅パターン(桜上水にも停車)であることから
  区間急行と同一と仮定した値であり、未確認です。** 正確な値が判明次第 `data.js` の
  `DURATION_MIN.kyuko` を修正してください。
- 本八幡・大島方面行きの電車は、新宿方面へは新線新宿経由で都営新宿線に直通するため、
  一覧上は新線新宿への到着予定時刻を「新宿方面到着予定」として表示しています。
- 桜上水止まりの電車(新宿まで直通しない)は一覧から除外しています。
- 実際の遅延・運休・臨時ダイヤの変更などは一切反映されません。あくまで時刻表(定刻)ベースの
  予定時刻です。

## ダイヤ改正時のデータ更新

`data.js` の `WEEKDAY_RAW`(および将来追加する場合は土休日データ)を差し替えるだけで、
表示ロジック側のコード変更なしに最新ダイヤへ追従できます。

## 技術構成

- HTML / CSS / JavaScript のみ(フレームワーク・外部ライブラリ・CDN依存なし)
- 時刻表データはビルド時ではなく `data.js` として静的にバンドルしているため、
  通信不要でそのまま表示できます
- ライトモード/ダークモードは `prefers-color-scheme` に自動追従します
