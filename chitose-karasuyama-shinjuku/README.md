# 千歳烏山→新宿 次発電車比較

京王線 千歳烏山駅から新宿方面への移動時、現在時刻から15分以内に発車する電車を一覧表示し、
(実際の)新宿駅へ最も早く着く電車を強調表示するツールです。新線新宿は目的地として扱いません。

## 使い方

このディレクトリの `index.html` をブラウザで開くだけで動作します。ビルドやサーバーは不要です。

- 上部に現在時刻を表示し、1秒ごとに一覧を更新します
- 各電車のカードには、発車時刻・種別・新宿到着予定時刻・所要時分・残り時間を表示します
- 本八幡・大島・新線新宿行きなど新宿へ直通しない電車は、笹塚で新宿行きの電車に乗り換える
  前提で新宿到着予定を計算し、カード内に乗り換え電車を明示します(詳細は後述)
- 一覧中で新宿到着が最も早く、かつ後続のどの電車にも追いつかれない(＝それより早く着く
  電車が現れない)電車にのみ「最速」バッジを表示します。あとから来る電車に追いつかれる
  (先に新宿へ着かれてしまう)電車は、その時点で一覧内の到着が最速に見えても強調しません
- 各カード下部の「見送ると…」の行で、その電車を見送って後続の電車に乗り換えた場合の
  到着時刻・差分を確認できます(後続の急行系が先に着く場合はプラス表示、遅くなる場合は
  マイナス表示になります)

## 新宿へ直通しない電車の扱い(笹塚乗り換え)

本八幡・大島・新線新宿行きの電車は、笹塚で京王新線(都営新宿線方面)へ分岐するため、
京王線の新宿駅には直通しません。これらの電車については、

1. 千歳烏山→笹塚の所要時分(種別ごとに算出。後述)をもとに笹塚到着予定を求め、
2. 笹塚到着予定より一定時間(乗換バッファ)以上あとに笹塚へ到着する新宿行き電車のうち、
   最も早く笹塚に着くものへ乗り換えると仮定して、
3. その電車の笹塚→新宿(4分と仮定)を加えて新宿到着予定を算出しています。

これにより、例えば「本八幡行きの急行に乗り、笹塚で後続の特急・各停へ乗り換えたほうが、
新宿行きの電車を千歳烏山で待つより早く新宿へ着く」ようなケースも一覧に反映されます。
カード内に「笹塚 ◯◯頃着 → ◯◯頃発 ◯◯(新宿行き・千歳烏山◯◯発)に乗り換え」の形式で
乗り換え電車を表示します。

## データについて・既知の制約

- 収録している時刻表は **平日ダイヤのみ** です。土休日ダイヤのデータは未取得のため、
  土休日にアクセスすると平日ダイヤを参考表示し、その旨を画面上部に注記します。
- 時刻表データ(`data.js`)は、京王電鉄「発車標準時刻表」(2026年8月17日改正・千歳烏山駅
  下り新宿方面)をユーザーが書き起こしたものをもとに作成しています。祝日ダイヤ(土休日扱い)
  は未対応で、`getDayType()` は曜日(土・日)のみで平日/土休日を判定しています。
- 種別ごとの千歳烏山→新宿所要時分は次の値を採用しています。特急(12分)・区間急行(14分)は
  複数の乗換案内サイトの表示から確認済みです。快速・各停(20分)は同様の情報源からの概算値です。
  **急行(14分)は、千歳烏山→新宿間で区間急行と同じ停車駅パターン(桜上水にも停車)であることから
  区間急行と同一と仮定した値であり、未確認です。** 正確な値が判明次第 `data.js` の
  `DURATION_MIN.kyuko` を修正してください。
- 笹塚乗り換えの計算には、次の未確認の仮定値を用いています(いずれも `data.js` に定義)。
  - **笹塚→新宿は種別によらず一律4分**(途中駅のないノンストップ区間であることによる仮定)
  - **千歳烏山→笹塚の所要時分 = 千歳烏山→新宿の所要時分 − 4分**(上記の逆算による推定)
  - **笹塚での乗り換えに最低2分を要する**(京王線・京王新線でホームが異なるためのバッファ)
  - 特急を含む全種別が笹塚に停車する前提としています(未確認)
- 桜上水止まりの電車(明大前より手前で運行を終える電車)は、笹塚にも到達しないため
  乗り換え計算の対象外とし、一覧から除外しています。
- 実際の遅延・運休・臨時ダイヤの変更などは一切反映されません。あくまで時刻表(定刻)ベースの
  予定時刻です。

## ダイヤ改正時のデータ更新

`data.js` の `WEEKDAY_RAW`(および将来追加する場合は土休日データ)を差し替えるだけで、
表示ロジック側のコード変更なしに最新ダイヤへ追従できます。

## 技術構成

- HTML / CSS / JavaScript のみ(フレームワーク・外部ライブラリ・CDN依存なし)
- 時刻表データはビルド時ではなく `data.js` として静的にバンドルしているため、
  通信不要でそのまま表示できます
- ライトモード/ダークモードは `prefers-color-scheme` に自動追従します
