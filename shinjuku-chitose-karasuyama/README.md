# 新宿→千歳烏山 次発電車比較

京王線 新宿駅から千歳烏山方面への移動時、現在時刻から15分以内に発車する電車を一覧表示し、
千歳烏山駅へ最も早く着く電車を強調表示するツールです。姉妹アプリ
[chitose-karasuyama-shinjuku](../chitose-karasuyama-shinjuku/)(千歳烏山→新宿)の逆方向版です。

## 使い方

このディレクトリの `index.html` をブラウザで開くだけで動作します。ビルドやサーバーは不要です。

- 上部に現在時刻を表示し、1秒ごとに一覧を更新します
- 各電車のカードには、発車時刻・種別・行き先・千歳烏山到着予定時刻・所要時分・残り時間を表示します
- 一覧中で千歳烏山到着が最も早く、かつ後続のどの電車にも追いつかれない(＝それより早く着く
  電車が現れない)電車にのみ緑色の「最速」バッジを表示します。あとから来る電車に追いつかれる
  (先に千歳烏山へ着かれてしまう)電車は、その時点で一覧内の到着が最速に見えても強調しません
- 「最速」の電車より後に、異なる(より遅い)到着時刻で最も早く着き、かつ同様に後続に
  追いつかれない電車には、青色の「次着」バッジを表示します。「最速」と到着時刻が
  完全に同着の電車には(同率1位のため)「次着」は付きません
- 各カード下部の「見送ると…」の行で、その電車を見送って後続の電車に乗り換えた場合の
  到着時刻・差分を確認できます

姉妹アプリと異なり、新宿発の電車はすべて新宿駅始発(京王線・都営新宿線方面への分岐の
影響を受けない)のため、途中駅での乗り換えを前提とした計算は行っていません。

## 一覧から除外している電車

- **桜上水行き**: 桜上水は新宿と千歳烏山の間(新宿寄り)の駅のため、桜上水行きの電車は
  千歳烏山に到達しません。
- **京王ライナー**: 新宿発車後、千歳烏山を含む多くの中間駅を通過するため、千歳烏山では
  乗降できないと考えられます(一般に知られている運行形態に基づく仮定・未確認)。

## データについて・既知の制約

- 収録している時刻表は **平日ダイヤのみ** です。土休日ダイヤのデータは未取得のため、
  土休日にアクセスすると平日ダイヤを参考表示し、その旨を画面上部に注記します。
- 時刻表データ(`data.js`)は、乗換案内サイトに表示された新宿駅の時刻表(2026年8月16日時点)を
  ユーザーが書き起こしたものをもとに作成しています。祝日ダイヤ(土休日扱い)は未対応で、
  `getDayType()` は曜日(土・日)のみで平日/土休日を判定しています。
- 姉妹アプリ(千歳烏山発・2026年8月17日改正)とは取得時点・出典が異なるため、
  細部の時刻が完全には一致しない可能性があります。
- **新宿→千歳烏山の所要時分は、姉妹アプリで採用している千歳烏山→新宿の所要時分を
  そのまま流用しています(上り下りで所要時分が同じという未確認の仮定)。** 特急12分・
  区間急行14分は姉妹アプリ側で複数の乗換案内サイトから確認済みの値ですが、この区間を
  逆方向に確認したものではありません。急行(14分)は区間急行との同一性を仮定した
  未確認値、快速・各停(20分)は概算値です。正確な値が判明次第 `data.js` の
  `DURATION_MIN` を修正してください。
- 行き先が「高尾行き」と表示されていた1件(20:02発)は、京王線に「高尾」という駅が
  存在しないため「高尾山口」の表記ゆれ(誤記)とみなし、高尾山口行きとして扱っています
  (要確認)。
- 実際の遅延・運休・臨時ダイヤの変更などは一切反映されません。あくまで時刻表(定刻)ベースの
  予定時刻です。

## ダイヤ改正時のデータ更新

`data.js` の `WEEKDAY_RAW`(および将来追加する場合は土休日データ)を差し替えるだけで、
表示ロジック側のコード変更なしに最新ダイヤへ追従できます。

## 技術構成

- HTML / CSS / JavaScript のみ(フレームワーク・外部ライブラリ・CDN依存なし)
- 時刻表データはビルド時ではなく `data.js` として静的にバンドルしているため、
  通信不要でそのまま表示できます
- ライトモード/ダークモードは `prefers-color-scheme` に自動追従します
